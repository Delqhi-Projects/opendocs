# OpenDocs User Guide

## Getting Started

### Creating Your First Document

1. Click "New Document" button
2. Enter a title
3. Press Enter to start writing

### Adding Blocks

Type `/` to open the block menu:
- Paragraph - regular text
- Headings (H1-H3) - structured headings
- Code - syntax-highlighted code blocks
- Database - relational data tables
- Automation - workflow builder
- AI Prompt - AI-generated content

### Using the Database Block

1. Click "Add Block" → "Database"
2. Create columns with types
3. Add rows of data
4. Use views: Table, Kanban, Calendar, Gallery

### Building Automations

1. Click "Add Block" → "Automation"
2. Add trigger nodes (manual, webhook, schedule)
3. Add logic nodes (if/else, switch, wait)
4. Add action nodes (email, webhook, n8n, WhatsApp)
5. Connect nodes with edges
6. Click "Run" to execute

### Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| Ctrl+S | Save |
| Ctrl+Z | Undo |
| Ctrl+Shift+Z | Redo |
| Ctrl+N | New Document |
| Ctrl+F | Find |
| Escape | Close modal |
